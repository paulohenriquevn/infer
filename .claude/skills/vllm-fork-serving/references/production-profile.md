# Production profile: every env var and flag

The full launch of `bench/server-vllm-dcp1-direct.sh` (DCP1) with each env var and flag explained. `bench/server-vllm-direct.sh` is identical except `--decode-context-parallel-size 4`. Both are generated by `bench/docker_to_direct.py` from the image launcher's `--print-command` output, so the values are the image's `glm53-flash` profile for `rtx-pro-6000-pcie`, plus two lines we add (`HF_HUB_OFFLINE=1`, `CUDA_VISIBLE_DEVICES`).

Rule: copy the whole set. Change a value only through the procedure in `../examples/change-one-flag-walkthrough.md`.

| Env var | Value | What it does | Source |
|---|---|---|---|
| `NCCL_NET_PLUGIN` | `none` | Which network plugin NCCL loads; "none" is an accepted value. The image's printed command sets `spcx` (Observed, `f3/resultados/rtx-20261105/print-command-glm53-tp4-dcp4-mtp3.sh`); our scripts override it with `none`, and every measured run since R1 used `none` (`ARQUITETURA.md §12`).
