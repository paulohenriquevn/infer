# infer

Serving the GLM-5.3-Flash model to about 10,000 developers who use coding agents, on NVIDIA RTX PRO 6000 Blackwell GPUs.

Start with [`docs/README.md`](docs/README.md): it gives the current state, the decisions taken, the open questions and the order to read the other documents. The build plan for AWS is [`docs/06-aws-implementation-plan.md`](docs/06-aws-implementation-plan.md).

The documents cite a benchmark harness and raw results under `f3/` and a working journal, `ARQUITETURA.md`. Those files are not in this repository yet.
